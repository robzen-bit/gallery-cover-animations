# Gallery Cover Animations

Motion prototypes for the 15 Zenfolio gallery cover layouts, plus the cover 9 circle alternate.

Open `index.html` in a browser to step through them in order. Use the sidebar, the ← → buttons or the arrow keys. **Replay** restarts the current cover's load animation.

- `covers/`: one self-contained HTML prototype per layout
- `SPEC.md`: the working motion spec (timings, easing, image entrances, layout notes)
